# F-NAL-SINAVI

FİNAL SINAVI için Bootstrap 5 kullanılarak hazırlanmış, modern ve mobil uyumlu tanıtım web sitesi projesidir.
Site; spor kulübünün hizmetlerini, kurslarını, eğitmenlerini ve iletişim bilgilerini sade ve etkili bir şekilde sunmayı amaçlar.
🚀 Özellikler

✅ Bootstrap 5 ile responsive (mobil uyumlu) tasarım
🎨 Koyu tema + kırmızı vurgu renkleri
🖋️ Google Fonts (Rubik Wet Paint) ile özel logo yazı tipi
🧑‍🏫 Eğitmen tanıtım alanı
🥋 Kurslar & antrenman programları
📩 İletişim formu
⚡ Hızlı, sade ve kullanıcı dostu arayüz

🛠️ Kullanılan Teknolojiler

HTML5
CSS3
Bootstrap 5.3
Google Fonts
Responsive Design
